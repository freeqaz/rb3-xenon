## 2. Behaviour bugs fixed (retail does something different)

All of these were confirmed on retail bytes. The full list is in the commit messages; these are
the ones that change what the game does.

- **BoxMapLighting::ApplyQueuedLights** (B):
  - It read the light count before the directional pass, so directional lights never reached
    the ambient cube.
  - It cross-wired the cube faces. Retail feeds +x, −x, +y, −y, +z, −z in that order.
- **CheckShadow** (B): the shadow texture matrix. Ours had a zero x row and biased only y.
  Retail scales x by 0.5 and biases x and y by 0.50097656 (`.rdata` `0x8207508C`).
- **RndShadowMap::PrepShadow** (B): both passes walk the real lights, in draw mode 1. The `RndMat`
  ctor resets three colour mods.
- **RndAmbientOcclusion::BuildObjectLists** (A): ours `unique_copy`'d onto `meshes.end()`, which
  writes past the vector. Retail runs `unique` in place.
- **RndParticleSys** (A): `SetRelativeMotion` writes one transform, not two. `FreeParticle`
  clears `prev` only on the pool path.
- **VorbisReader::DoRawSeek** (A): the nonce is the byte-swapped `byte/16`.
- **Fixed constants** (A): the AO tessellation defaults, the AO ray range and the particle start
  size are fixed values in retail. DC3 scales them by `gUnitsPerMeter`.
- **CharClipDriver::ExecuteEvent** (D): runs the event on the clip through `HandleType`. The old
  code exported a message to the owner's dir.
- **Character::DrawLodOrShadow** (D): the approximate-lighting update and the shadow-group
  fallback.
- **Character::DrawShadow** (D): now `(Transform, Plane)`, because both retail callers build the
  plane.
- **CharClip::FindNode** (D): returns null for `kPlayNoBlend`.
- **FileMerger::LaunchNextLoader** (D): the load position was uninitialised in one path.
- **XboxMapFile::GetFunction** (E): returns the previous map line's function.
- **HDCache::WriteDone** (E): the bit is `1 << (block % 32)`. Ours gave 0 for blocks ≥ 32.
- **Archive::Enumerate** (E): the recursive match is a `strncmp` prefix test.
- **WorldDir::Save** (E): rev 0x19, with no tail. MatOverride's writer now streams what its
  reader reads; it used to write a third field.
- **XboxPurchaser** (F): `Poll` was empty, so a purchase could never complete. `IsPurchasing`
  tested `== 1`.
- **MemcardMgr::ThreadCall_SaveGame** (F): returns `kMCFileExists` for an existing save not marked
  for replace.
- **Smaller game-side fixes** (F):
  - `SongData::AddKeyboardRangeShift` ends an open range at start + span.
  - `UIListState::Scroll` leaves the target alone when no entry is active.
  - Tour's sign-out sends `Message(init, 0)`.
  - `Singer::CreateMicClientID` calls BandUser's own virtual.
- **Modal API** (H): retail's signature is `(bool &fail, char *msg, bool wait)`.
  - `DebugModal` reads the flag with `lbz` and strcats into r4.
  - `Rnd::Modal` passes the byte to `CanModal`/`ModalDraw` and word-wraps r5.
  - `XboxMapFile::ParseStack` strcats into its fourth argument.
  - Only a failure modal now draws red and ends tiling.
- **TheDxShaderInclude** (H): a plain 4-byte `.data` object. It was a reference bound to a
  temporary.
- **BandDirector** (C): `OnMidiShot5Cleanup`, `PickShot` and `OnRbn2AddPostProc` are written from
  retail bytes. `OnPaletteSync` was a stub.

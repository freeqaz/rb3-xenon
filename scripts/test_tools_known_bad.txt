# ── HOW THIS FILE IS KEPT HONEST ──────────────────────────────────────────────
#
# CI runs `scripts/test_tools.py --ci --strict-manifest`, and --strict-manifest
# makes a STALE entry — one listed here that now PASSES — a BUILD FAILURE. So an
# entry cannot outlive the breakage it records: whoever fixes the test must
# delete its line in the same change, or CI stays red. That is the whole
# maintenance protocol, and it is enforced rather than advertised.
#
# The alternative was to let stale entries be merely *reported*, which is what
# this file did until 2026-09-11 — and it had rotted: SIX of its seven entries
# had started passing and nobody had pruned them (lane TESTCI). A printed
# warning nobody acts on is the rotting gate this repo keeps finding.
#
# ⚠ CONSEQUENCE, ACCEPTED DELIBERATELY: an entry for a test that is red in one
# environment and green in another is stale *somewhere* and therefore fatal
# *somewhere*. Do NOT record that class here — use CI_DESELECT in
# scripts/test_tools.py, which is not judged in either environment.
